# 依赖与版本

| 依赖 | 版本 | 作用 |
|---|---|---|
| `org.mapstruct:mapstruct` | 1.6.3 | 注解。实现类在 `target/generated-sources/annotations` |
| `mapstruct-processor` | 1.6.3 | 只放在 `annotationProcessorPaths`，不进运行时 |
| Lombok | Boot 3.5.16 管理的 1.18.x | 实体的 getter / setter |
| `lombok-mapstruct-binding` | 0.2.0 | 让两个处理器能看见对方生成的方法 |
| `spring-boot-starter-web` | 3.5.16 | 接口 |
| `springboot-common` | 本仓库 | 统一 `R`、`BusinessException` |

MapStruct 1.6 能直接映射 Java 21 的 record 和 `java.time`。VO、请求用 record；实体用可变类，因为局部更新要写回已有对象。
