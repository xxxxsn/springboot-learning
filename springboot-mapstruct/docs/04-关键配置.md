# 关键配置

端口：

```yaml
server:
  port: 8030
```

没有为 MapStruct 准备的 `application.yml` 开关。映射关系写在注解上，生成发生在编译期。

父 POM 锁定：

```xml
<mapstruct.version>1.6.3</mapstruct.version>
<lombok-mapstruct-binding.version>0.2.0</lombok-mapstruct-binding.version>
```

模块里的编译器路径：

```xml
<annotationProcessorPaths>
    <path>
        <groupId>org.mapstruct</groupId>
        <artifactId>mapstruct-processor</artifactId>
        <version>${mapstruct.version}</version>
    </path>
    <path>
        <groupId>org.projectlombok</groupId>
        <artifactId>lombok</artifactId>
        <version>${lombok.version}</version>
    </path>
    <path>
        <groupId>org.projectlombok</groupId>
        <artifactId>lombok-mapstruct-binding</artifactId>
        <version>${lombok-mapstruct-binding.version}</version>
    </path>
</annotationProcessorPaths>
```

`@Mapper` 上这几项是行为开关，不是配置文件：

| 项 | 本模块取值 | 原因 |
|---|---|---|
| `componentModel` | `spring` | 生成 `@Component`，构造器注入 |
| `injectionStrategy` | `CONSTRUCTOR` | 和手写的 Service 一样 |
| `uses` | `MoneyMapper` | 金额换算单独放 |
| `unmappedTargetPolicy` | `ERROR` | 目标少映射一个字段就编译失败 |
| `unmappedSourcePolicy` | `IGNORE` | 摘要 VO 本来就比实体少字段 |

JSON 的日期格式故意不在这里改。`createdAt` 走 Boot 默认的 ISO-8601，`createdAtText` 才是 MapStruct 的 `dateFormat`。两边对照着看。
