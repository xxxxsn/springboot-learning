# 对照方案

| 需求 | 本模块 | 其他 |
|---|---|---|
| Entity / DTO / VO、嵌套、集合、局部更新 | ✅ MapStruct | 字段很少时手写 setter |
| 同名浅拷贝 | 能做，但是运行时才发现类型不匹配 | Spring `BeanUtils`，本仓库不单开模块 |
| 入参空值、范围、分组 | ❌ | #24 springboot-web-validation |
| JSON 日期、Long 精度、枚举码 | 只负责对象到对象；id 在 VO 上已是 String | #26 springboot-web-jackson |
| 统一响应 `R` | 复用 | #1 springboot-common |
| 字段校验失败的错误体 | 映射阶段的业务异常走 `code=400` | #25 管 HTTP 状态和 ProblemDetail |
