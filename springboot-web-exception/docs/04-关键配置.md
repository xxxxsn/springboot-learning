# 关键配置

```yaml
demo:
  exception:
    style: ENVELOPE          # PROBLEM_DETAIL 见 application-problem.yml

spring:
  mvc:
    throw-exception-if-no-handler-found: true
  web:
    resources:
      add-mappings: false   # 配合上面，让未知路径走异常
```

切换 ProblemDetail：

```bash
cmd /c "mvn -pl springboot-web-exception spring-boot:run -Dspring-boot.run.arguments=--spring.profiles.active=problem"
```
