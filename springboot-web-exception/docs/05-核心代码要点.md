# 核心代码要点

## 封装分层（对企业项目）

1. **错误码**：`ErrorCode` + 域枚举实现 `HttpStatusErrorCode`
2. **映射**：`ErrorHttpStatusMapper`（显式状态 / common 码 / 后三位对齐）
3. **组装**：`ErrorResponseFactory`（信封或 ProblemDetail）
4. **拦截**：`EnterpriseExceptionAdvice`（分类处理 + 日志级别）
5. **链路**：`TraceIdFilter`（请求头优先，否则生成）

## 信封示例

```json
{
  "code": 20404,
  "message": "订单不存在",
  "traceId": "abc",
  "path": "/api/exception/orders/999",
  "timestamp": "2026-11-21T10:00:00Z"
}
```

## ProblemDetail 扩展

标准字段 + `code` / `traceId` / `errors`（`setProperty`）。
