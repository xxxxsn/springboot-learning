# 常见坑与排障

| 现象 | 原因 | 处理 |
|---|---|---|
| 业务失败仍 HTTP 200 | 落到了 common 默认处理器 | 确认本模块 Advice `@Order(HIGHEST)` |
| 未知 URL 不是统一错误体 | 未开 `throw-exception-if-no-handler-found` | 按本模块 yml 配置 |
| ProblemDetail 没有 code | 只返回了标准字段 | 用 `setProperty("code", ...)` |
| 前端看到堆栈 | 把异常 message 直接回传 | 系统异常固定文案，细节只打日志 |
| 与 #24 字段错误格式不一致 | #24 放在 `R.data`，本模块用 `errors` | 下沉 common 时统一一种结构 |
