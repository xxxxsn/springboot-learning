# 验证步骤

```bash
cmd /c "mvn -pl springboot-web-exception -am test"
cmd /c "mvn -pl springboot-web-exception -am spring-boot:run"
```

| 请求 | 期望 |
|---|---|
| `GET /orders/999999` | HTTP 404，`code=20404`，含 `traceId` |
| `POST /orders/1002/cancel` | HTTP 409，`code=20409` |
| `POST /orders` 非法体 | HTTP 400，`errors` 多字段 |
| `GET /forbidden` | HTTP 403 |
| `GET /boom` | HTTP 500，文案脱敏 |
| `GET /no-such-api` | HTTP 404 |
| profile=`problem` | body 为 ProblemDetail |
