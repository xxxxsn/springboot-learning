# 验证步骤

```bash
mvn -pl springboot-lombok-hutool -am spring-boot:run
```

| 请求 | 期望 |
|---|---|
| `GET /api/lombok/overview` | 含 Builder/`@Slf4j` 说明 |
| `POST /api/lombok/jackson` + JSON body | 反序列化成功，返回 username/age |
| `GET /api/lombok/equals` | DataEmployee 变更后 equals=false；SafeEmployee 仍 true |
| `GET /api/hutool/all` | 含 str/date/id/digest/bean/json |
| `GET /api/guava/all` | 含 immutable/partition/joiner/precondition/cache |

单测：

```bash
mvn -pl springboot-lombok-hutool -am test
```
