# 核心代码要点

## Lombok

- `UserDto`：拆开 Getter/Setter/Builder/构造器（比 Entity 上直接 `@Data` 更可控）
- `BuilderUser`：`@Builder` + `@NoArgsConstructor` + `@AllArgsConstructor`，Jackson 可反序列化
- `DataEmployee` vs `SafeEmployee`：可变集合是否参与 equals
- `@Slf4j` / `@RequiredArgsConstructor`：日志与构造注入

## Hutool

`StrUtil`、`CollUtil`、`DateUtil`/`LocalDateTimeUtil`、`IdUtil`、`DigestUtil`、`BeanUtil`、`JSONUtil`。

## Guava

`ImmutableList/Map`、`Lists.partition`、`Joiner/Splitter`、`Preconditions`、`LoadingCache`。

接口统一返回 `case/input/output/pitfall`，便于对照查阅。
