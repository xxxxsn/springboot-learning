# 常见坑与排障

| 现象 | 原因 | 处理 |
|---|---|---|
| IDE 报找不到 getter | 未开注解处理 / 无 Lombok 插件 | 开启 Annotation Processing |
| Jackson 反序列化 Builder 类失败 | 只有 `@Builder`，无无参构造 | 加 `@NoArgsConstructor` + `@AllArgsConstructor`，或 `@Jacksonized` |
| HashSet 里对象「丢失」 | `@Data` 把可变集合纳入 equals/hashCode | `onlyExplicitlyIncluded` + 业务主键 Include |
| Entity 用 `@Data` | toString/equals 可能触发懒加载或环 | Entity 慎用；DTO 拆开注解 |
| Hutool JSON 与全局 Jackson 行为不一致 | 两套实现 | Web 层继续 Jackson；脚本/临时转换才用 JSONUtil |
| 多实例雪花 ID 冲突 | workerId 相同 | 按实例分配 workerId/datacenterId |
| Guava Cache 多节点不一致 | 本地缓存 | 分布式场景换 Redis 等 |
