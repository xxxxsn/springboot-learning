# 验证步骤

```bash
mvn -pl springboot-lifecycle -am spring-boot:run
```

| 请求 | 期望 |
|---|---|
| `GET /api/lifecycle/timeline` | 多条记录，含 bootstrap/bean/runner/event/smart |
| `GET /api/lifecycle/summary` | 按 phase 分组 |
| `GET /api/lifecycle/status` | `initializerReady=true`，`smartLifecycleRunning=true` |

优雅停机手工观察：

1. 调用 `GET /api/lifecycle/slow?seconds=8`
2. 在 8 秒内停止进程（命令行 Ctrl+C 更接近真实）
3. 日志中应能看到 `SmartLifecycle.stop`、`@PreDestroy` 等 shutdown 记录
