# 常见坑与排障

| 现象 | 原因 | 处理 |
|---|---|---|
| timeline 没有 RunListener 记录 | 未注册 spring.factories 或构造器签名不对 | 必须提供 `(SpringApplication, String[])` 构造；检查 META-INF |
| Initializer 未执行 | 未写 spring.factories | 与 AutoConfiguration.imports 职责不同，勿混用 |
| ApplicationRunner 顺序不对 | 未设 `@Order` | Order 数值越小越先执行 |
| SmartLifecycle 晚于 Runner | 正常 | Boot 在 ApplicationReady 前后管理 Lifecycle，以 timeline 为准 |
| IDE 点停止看不到优雅效果 | IDE 可能直接杀进程 | 用终端 Ctrl+C 或发送 SIGTERM |
| 停机超时仍强制退出 | 超过 `timeout-per-shutdown-phase` | 调大超时或缩短业务收尾时间 |
