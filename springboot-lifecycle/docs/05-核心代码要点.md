# 核心代码要点

## 建议对照的启动顺序（简化）

1. `RunListener` 构造 / `starting`
2. `environmentPrepared`
3. `ApplicationContextInitializer`
4. `contextPrepared` → `contextLoaded`
5. Bean：构造 → Aware → `@PostConstruct` → `InitializingBean`
6. `RunListener.started` / `ApplicationStartedEvent`
7. `ApplicationRunner`（Order 小的先）→ `CommandLineRunner`
8. `SmartLifecycle.start`
9. `RunListener.ready` / `ApplicationReadyEvent`

停机时大致相反：拒绝新请求 → `SmartLifecycle.stop` → `@PreDestroy` / `DisposableBean` → `ContextClosedEvent`。

用 `GET /api/lifecycle/timeline` 看本机真实顺序。
