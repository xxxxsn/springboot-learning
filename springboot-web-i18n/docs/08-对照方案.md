# 对照方案

| 方案 | 谁出句子 | 何时用 |
|---|---|---|
| 返回 i18n key（本模块推荐） | vue-i18n 或 `@nuxtjs/i18n` | 前后端分离，多种前端各维护 zh-CN / en |
| `MessageSource` + `Accept-Language`（`GET /api/i18n/messages`） | Spring | 服务端模板、邮件、短信；或暂时没有前端工程时核对译文 |
| common 直接返回中文 | 无 | 内部接口、还没做语言包的模块。不要和 key 混在同一个对外错误里 |

面试题库项目用的是第一种：`ErrorCode.message` 只放 key，后台 `admin/locales/{zh-CN,en}.yaml`，门户 `portal/i18n/locales/{zh-CN,en}.json`。本模块把同一形状收成 `frontend-catalog`，没有把 Vue 和 Nuxt 工程嵌进来。

不在这里做的对照：整站文案抽取、浏览器语言自动跳转。Nuxt 那个项目把 `detectBrowserLanguage` 关掉，默认 zh-CN，避免刷新时语言乱跳。那是前端策略，写在这里只作提醒。
