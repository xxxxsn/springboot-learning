# 依赖与版本

| 依赖 | 版本 | 用途 |
|---|---|---|
| Spring Boot | 3.5.16（父 POM） | `MessageSourceAutoConfiguration`，默认 basename `messages`，编码 UTF-8 |
| spring-boot-starter-web | 随 Boot | MVC、`Accept-Language` |
| spring-boot-starter-validation | 随 Boot | `@NotBlank` |
| springboot-common | 1.0.0-SNAPSHOT | 统一 `R`、`BusinessException` |

没有 vue-i18n、`@nuxtjs/i18n` 的运行时依赖。对应文案是资源文件，形状和面试题库项目一致：

- `frontend-catalog/vue/zh-CN.yaml`、`en.yaml`：给 vue-i18n
- `frontend-catalog/nuxt/zh-CN.json`、`en.json`：给 `@nuxtjs/i18n`

前端查找方式：接口 `message` 为 `auth.login.invalid_credentials` 时，调用 `t("errors." + message)`，因为文案都挂在 `errors` 下面。
