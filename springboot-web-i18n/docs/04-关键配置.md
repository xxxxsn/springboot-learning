# 关键配置

```yaml
server:
  port: 8031

spring:
  messages:
    basename: messages
    encoding: UTF-8
    fallback-to-system-locale: false
```

`messages.properties` 与 `messages_zh_CN.properties` 内容相同，作为默认语言。`messages_en.properties` 是英文。

`fallback-to-system-locale: false`：某个 key 在所请求语言里缺失时，不要再去用操作系统语言。中文 Windows 上带 `Accept-Language: en` 时，缺 key 应落回 basename 默认文件，而不是悄悄变成中文。

本模块三个 key：

| key | 数字码 | 何时出现 |
|---|---|---|
| `common.param_invalid` | 40000 | 字段空白，或 JSON 读不出来 |
| `auth.login.invalid_credentials` | 41001 | 密码不是教学口令 `secret` |
| `file.type_not_allowed` | 44002 | 扩展名不是 png / jpg / jpeg / webp |
