# 验证步骤

在仓库根目录：

```bash
mvn -pl springboot-web-i18n -am test
```

测试覆盖：口令错误、口令正确、用户名为空、扩展名 `.exe`、`Accept-Language` 中英切换、四份前端文案的 key 集合一致。

手工看接口时启动本模块，端口 8031，按 `api.http` 依次点。期望：

| 请求 | code | message |
|---|---|---|
| 登录密码 `wrong` | 41001 | `auth.login.invalid_credentials` |
| 登录密码 `secret` | 0 | `成功`（common 的成功文案，不是错误 key） |
| 用户名为空 | 40000 | `common.param_invalid` |
| `note.exe` | 44002 | `file.type_not_allowed` |
| `avatar.png` | 0 | `成功` |
| `GET /messages?key=auth.login.invalid_credentials` 且 `Accept-Language: en` | 0 | data.text 为 `Incorrect username or password` |
| 同一 key，`Accept-Language: zh-CN` | 0 | data.text 为 `用户名或密码错误` |

HTTP 状态保持 200，业务是否成功看 body 里的 `code`。这是 `springboot-common` 的约定。
