# 常见坑与排障

| 现象 | 原因 | 处理 |
|---|---|---|
| 校验失败返回「username 不能为空」 | 请求没进本模块的 `I18nExceptionHandler`，被 common 拼了中文 | 确认类上有 `@Order(HIGHEST_PRECEDENCE)`，且启动类能扫到 `com.xiesn.springboot.i18n` |
| `Accept-Language: en` 仍是中文 | `fallback-to-system-locale` 为 true，英文文件缺 key 后漂到系统语言 | 保持 false，并让 `messages_en.properties` 写全 |
| 前端显示整段 key | 文案文件没有对应叶子，或 `t()` 少了 `errors.` 前缀 | key `a.b` 对应 `errors.a.b`；中英文文件一起补 |
| 只改了 yaml 没改 json | 后台和门户各有一份 | 四份 `frontend-catalog` 的 key 集合必须相同，测试会比对 |
| properties 里中文变成问号 | 文件不是 UTF-8 | 保持 UTF-8，并设置 `spring.messages.encoding=UTF-8` |
| 把口令打进日志 | 演示登录时顺手打印了 password | 日志只写用户名 |

成功响应的 `message` 仍是 common 的「成功」。错误才使用 key。不要把成功文案也改成 key，除非整个 `R.ok()` 一起改，那会波及已完成的 hello、jasypt。
