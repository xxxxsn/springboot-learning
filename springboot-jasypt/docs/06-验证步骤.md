# 验证步骤

1. 运行 `JasyptApplication`（教学默认主密钥 `springboot-learning-demo`）
2. 启动日志应出现：`Jasypt 解密自检通过`
3. `GET http://localhost:8011/api/jasypt/secrets`
   - `dbPasswordDecrypted` = `MySecretDbPassword!`
4. `POST /api/jasypt/encrypt?plainText=abc` → 得到新的 `ENC(...)`
5. 把返回的 ENC 再丢给 `/decrypt` 应还原明文
6. 也可用模块内 `api.http` 一键点

生产请用环境变量覆盖：

```bash
set JASYPT_ENCRYPTOR_PASSWORD=你的强密码
```
