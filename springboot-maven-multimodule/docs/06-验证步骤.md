# 验证步骤

## 构建

```bash
# 在 springboot-learning 根目录
mvn -pl springboot-maven-multimodule -am package -DskipTests
```

## 启动

```bash
mvn -pl springboot-maven-multimodule/demo-web -am spring-boot:run
```

或 IDE 运行 `MultimoduleDemoApplication`。

## 接口

| 请求 | 期望 |
|---|---|
| `GET /api/products` | `code=0`，3 条商品 |
| `GET /api/products/1` | 名称含「Spring Boot」 |
| `GET /api/products/999` | `code=404` |
| `GET /api/products/meta/modules` | 返回四层模块说明 |

也可用模块内 `api.http`。
