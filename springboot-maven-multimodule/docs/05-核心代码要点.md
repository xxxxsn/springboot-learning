# 核心代码要点

| 位置 | 说明 |
|---|---|
| `demo-api/.../ProductDto` | 跨模块传输对象 |
| `demo-api/.../ProductFacade` | 业务门面接口 |
| `demo-service/.../ProductFacadeImpl` | `@Service` 实现 + 内存数据 |
| `demo-web/.../MultimoduleDemoApplication` | 唯一启动类，扫描 web+service |
| `demo-web/.../ProductController` | HTTP 编排，返回统一 `R` |
| `demo-bom/pom.xml` | 对外 BOM |
| 聚合 `pom.xml` | modules + dependencyManagement + Nexus 注释示例 |

依赖方向必须单向：`web → service → api`，禁止 api 依赖 web。
