# 常见坑与排障

1. **启动类扫不到 Service**  
   `scanBasePackages` 要包含 `...service`，否则 `ProductFacade` 无法注入。

2. **在 api/service 上挂了 spring-boot-maven-plugin**  
   非启动模块会被打成可执行 fat jar，依赖关系变乱。只给 `demo-web` 配该插件。

3. **父 POM import 自己的子 BOM**  
   容易形成循环依赖；本案例父 POM 直接 `dependencyManagement`，BOM 留给外部工程。

4. **子模块写死 version**  
   升级时漏改。应依赖父/`dependencyManagement` 统一版本。

5. **api 模块引入了 web starter**  
   契约层变重，其它非 Web 消费者也被拖进 Servlet 依赖。
