# 依赖与版本

## 模块关系

| 模块 | 依赖 |
|---|---|
| demo-api | 无（保持轻量） |
| demo-service | demo-api、springboot-common、spring-context |
| demo-web | demo-service、springboot-common、spring-boot-starter-web |
| demo-bom | 无代码，仅 `dependencyManagement` |

## 版本怎么管

1. **聚合父 POM** 的 `dependencyManagement`：本案例内部子模块不写 version  
2. **demo-bom**：内容与上面类似，用于 `mvn deploy` 后给公司其它工程：

```xml
<dependencyManagement>
  <dependencies>
    <dependency>
      <groupId>com.xiesn</groupId>
      <artifactId>demo-bom</artifactId>
      <version>1.0.0-SNAPSHOT</version>
      <type>pom</type>
      <scope>import</scope>
    </dependency>
  </dependencies>
</dependencyManagement>
```

3. 全局 Boot / 三方版本仍由最外层 `springboot-learning` 父工程锁定
