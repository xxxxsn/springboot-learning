# 验证步骤

```bash
cmd /c "mvn -pl springboot-logback -am spring-boot:run"
```

| 请求 | 期望 |
|---|---|
| `GET /api/logback/status` | logback=true |
| `GET /api/logback/sample` + `X-User-Id` | 响应头 Trace-Id；app.log 含 MDC |
| `GET /api/logback/business` | 生成 business.log |

JSON 控制台：

```bash
cmd /c "mvn -pl springboot-logback spring-boot:run -Dspring-boot.run.arguments=--spring.profiles.active=json"
```
