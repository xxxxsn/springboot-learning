# 核心代码要点

| 包/类 | 作用 |
|---|---|
| `result.R` | 统一响应 `code/message/data` |
| `result.ErrorCode` / `CommonErrorCode` | 错误码约定 |
| `exception.BusinessException` | 可预期业务异常 |
| `exception.GlobalExceptionHandler` | 转成 `R`，校验/未知异常兜底 |
| `entity.BaseEntity` | id、创建/修改时间、逻辑删除 |
| `page.PageQuery` / `PageResult` | 分页入参（含 offset）与出参 |
| `util.AssertUtils` / `StringUtils` | 业务断言、空白判断 |
| `config.CommonAutoConfiguration` | Boot 3 自动配置入口 |

代码根路径：`src/main/java/com/xiesn/springboot/common/`
