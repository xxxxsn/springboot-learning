 常见坑与排障

| 现象 | 原因 | 处理 |
|---|---|---|
| ServiceLoader 为空 | services 文件名不是接口全名，或实现类无无参构造 | 检查 `META-INF/services/...` 与 public 无参构造 |
| Java SPI 实现进不了 `List<MessagePlugin>` | 未标 `@Component`，不是 Spring Bean | 预期行为；要容器管理就改成 Bean 或手动注册 |
| spring.factories 加载不到 | key 写错 / 文件位置错 | 必须在 `META-INF/spring.factories` |
| 把 AutoConfiguration 仍写进 spring.factories | Boot 3 已迁移 | 改用 `AutoConfiguration.imports`（见 #2） |
| 同名插件冲突 | 多实现 name 重复 | 约定唯一 name，或加 @Order / Primary |
