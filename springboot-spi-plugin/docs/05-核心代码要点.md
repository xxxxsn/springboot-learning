 核心代码要点

## 三条发现路径

1. **Java SPI**：`ServiceLoader.load(MessagePlugin.class)` → sms / email  
2. **Spring Bean**：`List<MessagePlugin>` 注入 → 过滤 `discovery=spring-bean` → push / wechat  
3. **SpringFactoriesLoader**：加载自定义 `PluginExtension` → audit / metrics  

## 选型直觉

| 诉求 | 更合适 |
|---|---|
| 第三方 jar 按约定暴露实现、无 Spring | Java SPI |
| 需要注入、事务、配置绑定 | Spring `@Component` 策略 |
| 写 Boot 扩展点 / starter | factories 或 AutoConfiguration.imports |
| 运行时热插拔独立插件包 | #415 PF4J |
