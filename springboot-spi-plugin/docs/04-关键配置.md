## Java SPI 注册

文件：`META-INF/services/com.xiesn.springboot.spi.plugin.api.MessagePlugin`

每行一个实现类全限定名。

## Spring Factories 注册

文件：`META-INF/spring.factories`

```properties
com.xiesn.springboot.spi.plugin.springfactories.PluginExtension=\
com.xiesn...AuditPluginExtension,\
com.xiesn...MetricsPluginExtension
```

注意：Boot 3 的 **AutoConfiguration** 不再写在 spring.factories，而写在 `AutoConfiguration.imports`。
