# 文档放置约定

## 回来时怎么找

1. [`进度.md`](进度.md) — 哪些做完了、下次做什么  
2. [`学习观测指南.md`](学习观测指南.md) — 日志 / 接口怎么看  
3. [`索引.md`](索引.md) — 模块状态 + 链接  
4. 模块 `README.md` — 八节摘要（含「怎么观察」）  
5. 模块 `docs/0x-*.md` — 展开细节  

## 总览文件

| 位置 | 用途 |
|---|---|
| [`../SpringBoot3-Java21-计划.md`](../SpringBoot3-Java21-计划.md) | 百科总清单、场景索引、选型表 |
| [`进度.md`](进度.md) | 实现进度 |
| [`学习观测指南.md`](学习观测指南.md) | 各模块用日志还是接口观察 |
| [`索引.md`](索引.md) | 模块文档速链 |
| `../springboot-xxx/README.md` | 模块入口 |
| `../springboot-xxx/docs/*.md` | 模块展开笔记 |

## 子模块 docs 固定 8 个文件

```
docs/
  01-适用场景.md
  02-频率与推荐度.md
  03-依赖与版本.md
  04-关键配置.md
  05-核心代码要点.md
  06-验证步骤.md
  07-常见坑与排障.md
  08-对照方案.md
```

## 完成一个模块时记得改

- [ ] 代码（类/方法中文注释）
- [ ] 模块 `README.md` 八节写满
- [ ] 模块 `docs/01~08` 补全（至少不留空标题）
- [ ] `api.http` 可点通
- [ ] [`进度.md`](进度.md) 标记已完成
- [ ] [`索引.md`](索引.md) 状态改为「已完成」
