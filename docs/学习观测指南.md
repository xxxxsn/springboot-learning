# 学习观测指南

> 怎么用日志 / 接口 / 文件看懂每个已完成模块。  
> 原则：**顺序、副作用、脱敏、落盘、异步** → 优先日志；**契约、状态码、字段错误** → 优先接口。

## 观测方式图例

| 标记 | 含义 |
|---|---|
| 日志优先 | 控制台或 `logs/` 才是主证据 |
| 接口优先 | HTTP 响应 / 状态码即可验收 |
| 混合 | 接口触发，日志对照细节 |

| # | 模块 | 方式 | 先看什么 |

| 11 | jasypt | 日志优先 | 启动：`Jasypt 解密自检通过/未通过`；再调 `/api/jasypt/secrets` |
| 14 | lifecycle | 日志优先 | 启动/停机控制台 `[lifecycle] seq=...`；`/timeline` 只是汇总 |
| 16 | spi-plugin | 接口优先 | `GET /api/spi/overview` |
| 17 | docker-compose | 混合 | `/redis/ping`；Docker 容器日志 / `docker compose ps` |
| 18 | logback | 日志优先 | `logs/springboot-logback/*.log` + MDC；接口只负责打点 |
| 19 | log4j2 | 日志优先 | 异步 burst 控制台耗时 + 日志文件；对照 #18 |

## 推荐学习顺序（按观测习惯）

1. **先会看日志**：#18 logback → #19 log4j2 → #14 lifecycle  
2. **再看 Web 契约**：#23 restful → #24 validation → #25 exception → #26 jackson  
3. **再看请求链路**：#27 interceptor → #28 resolver → #29 cors  
4. **配置与插件**：#9 profiles → #11 jasypt → #16 spi → #17 docker-compose  

## IDE 建议

- 用模块内 `api.http` 点请求，**同时盯 Run 窗口日志**
- 日志模块看文件：工程根下 `logs/springboot-*/`
- Windows 启动带参数时用 `cmd /c "mvn ..."`，避免 PowerShell 吃掉 `-D`
