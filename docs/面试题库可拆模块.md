## 1. 建议改写或新开

这五条和百科现稿对不上，优先单独写成模块笔记。

### 1.1 i18n：错误码 key + 双端文案（改写 #31，已落地 `springboot-web-i18n`，端口 8031）

同意单独成模块，但不另拆三个。百科 #31 `springboot-web-i18n` 现在写的是 Spring `MessageSource`，级别 P2 / 了解。面试项目没用 `MessageSource`。

学什么：

- 后端 `ErrorCode.message` 只放 i18n key（如 `auth.login.invalid_credentials`），响应体不带面向用户的中文。见 `server/src/main/java/com/interviewhub/common/exception/ErrorCode.java`。
- 后台 `vue-i18n`，文案在 `admin/locales/zh-CN.yaml` 与 `admin/locales/en.yaml`，前端用 `t(\`errors.${messageKey}\`)` 翻译。
- 前台 `@nuxtjs/i18n` 10.6.0，文案在 `portal/i18n/locales/zh-CN.json` 与 `en.json`。`nuxt.config.ts` 使用 `prefix_except_default`，默认 zh-CN，关闭浏览器语言探测。
- 新增 key 时两种语言一起补，不留空占位。

对照：Spring `MessageSource` + `messages_zh_CN.properties`。适合服务端直接渲染页面；前后端分离时用错误码 key 更合适。

不带进模块：题目、分类、题库的业务文案。演示用登录失败、参数校验、文件类型不允许三个 key 即可。

### 1.2 RustFS + S3（新开 #449 `springboot-file-rustfs`）

同意单独成模块。百科 #166 推荐 MinIO，不替换它。面试项目改用 RustFS，是因为 MinIO 社区版已停止发布镜像；生产仍可换成阿里云 OSS / 腾讯云 COS，业务代码只认 S3。

学什么：

- Compose 服务 `rustfs/rustfs:1.0.6`，API `9000`、控制台 `9001`。见 `deploy/docker-compose.yml`。
- `StorageConfig` 用 AWS SDK v2 `S3Client`：`endpointOverride`、`forcePathStyle(true)`、静态密钥。SDK 2.30 起默认给每次上传加 CRC 校验头，OSS / COS / RustFS 不认，要设 `RequestChecksumCalculation.WHEN_REQUIRED` 与 `ResponseChecksumValidation.WHEN_REQUIRED`。HTTP 客户端用 `UrlConnectionHttpClient`，排除 Netty 与 Apache 客户端。
- `FileStorageService` 按文件头判断图片类型，对象键 `yyyy/MM/dd/{uuid}.ext`，`Cache-Control` 长期缓存。接口返回站内路径 `/files/...`，不返回存储内网地址。前台 `nuxt.config.ts` 把 `/files/**` 反代到 `http://127.0.0.1:9000/interview-hub/**`。
- 配置在 `app.storage`：`endpoint`、`region`、`bucket`、`access-key`、`secret-key`、`path-style-access`。

对照：#166 MinIO、#167 x-file-storage、云 OSS。同一套 `S3Client` 换 endpoint 即可。

不带进模块：题库图标、Markdown 粘贴图片的业务页面。演示一个「上传图片 → 返回 `/files/` 路径 → 浏览器能打开」。

### 1.3 Boot 4 坐标（补 #231，并改文档选型说明）

不新开号。#231 已是「3.5 → 4.x 迁移」。面试项目是一份已经跑起来的 Boot 4.1.2 样本，写 #231 时直接摘这些差异：

- Web：`spring-boot-starter-webmvc`，不是 Boot 3 的 `spring-boot-starter-web`。另外为 SSE / WebClient 引入了 `spring-boot-starter-webflux`。
- ORM：`mybatis-plus-spring-boot4-starter` 3.5.18.1，另加 `mybatis-plus-jsqlparser`。
- 鉴权：`sa-token-spring-boot4-starter` 1.46.0，会话用 `sa-token-redis-template`。
- 文档：`springdoc-openapi-starter-webmvc-ui` 3.2.0。Knife4j 不适配 Boot 4，所以百科里「文档推荐 Knife4j、springdoc 作对照」在 Boot 4 上要反过来：Boot 4 用 springdoc，#46 标成 Boot 3 方案。
- AOP：`spring-boot-starter-aspectj`。

不带进模块：整站业务。用一个能启动的空接口加上 Swagger UI 即可。

### 1.4 Apache Fesod 导入（改写 #170 的实现选型）

不新开号。#170 现在写 FastExcel。面试项目选型说明里 EasyExcel 已停更，用的是后继 **Apache Fesod** `fesod-sheet` 2.1.0-incubating。

学什么：

- 两段式：`POST` 预览做校验，全部通过才把解析结果放进 Redis（带过期时间、绑当前管理员）；确认时取出并删除，再入库。
- 校验失败返回行级问题码，由前端 i18n 翻译，不在后端拼中文。
- 上传限制：xlsx / xls，请求体上限配合 `spring.servlet.multipart` 与 Tomcat `max-swallow-size`（默认 2MB 时，超限连接会被直接断开，客户端拿不到 413 响应体）。

对照：#170 FastExcel、#169 POI、#171 异步导入导出中心。Fesod 这一版是同步预览 + 确认，不是百万行异步任务。

不带进模块：题目字段（难度、VIP、所属题库）。演示「用户 + 邮箱」三列模板即可。

### 1.5 Spring AI 2.0：兼容协议、备用模型、SSE（补 #232、#39）

不新开号。#232 是 Spring AI 对话与流式，#39 是 `SseEmitter`。面试项目是 Boot 4 上的 **Spring AI 2.0.2**，协议走 OpenAI 兼容接口。

学什么：

- `spring.ai.model.chat=none`（embedding / image 等同理），避免没配密钥时自动配置把启动打挂。密钥非空时再手工建 `OpenAiChatModel`。
- 默认 `base-url` 指向 DeepSeek（`https://api.deepseek.com`），模型名走配置。DeepSeek 思考模式默认开，OpenAI 兼容请求用 `extraBody.thinking.type=disabled`，否则答案慢、还可能把思维链和正文搅在一起。`deepseek*` 用 `temperature` + `maxTokens`；`gpt-5` / `o1` / `o3` / `o4` 不支持 `temperature`，改 `reasoningEffort` + `maxCompletionTokens`。
- 主模型 20 秒没有首个非空片段，或直接失败且还没吐字，整段改走备用模型一次。已经吐过字就不再切换。未配置密钥时同步抛业务异常，不要放进已经开始的 `Flux`。
- 接口同时声明 `text/event-stream` 和 `application/json`，否则未配置密钥时的 JSON 错误会被当成不可接受的媒体类型。
- 日志只打异常类名，不打密钥、题干、答案。

对照：#232 单模型对话、#39 `SseEmitter`、#238 LangChain4j。客户端拼接 SSE 时不要把载荷开头的空格删掉：Spring 写出的是 `data:` 紧贴内容，单独一个空格片段是 Markdown 标题和正文之间的空格，删掉会变成 `##结论`。

不带进模块：按题干生成面试答案的提示词和题目编辑页。演示「流式复述一段固定 Markdown」即可。

## 3. 不拆成学习模块

下面是刷题站业务，换一个项目用不上，不进百科编号：

- 分类、题库、题目、标签的增删改查，以及分类与题库、题库与题目的多对多。
- 题库内组题：批量加入、移出、只重排当前这批 id。
- 题目批量改状态（草稿 / 已发布）、首次发布写 `published_at`、重算题库 `question_count`。
- 收藏、VIP「到期时间晚于现在才返回答案」。
- 浏览量总数加按日 `question_view_day` 的累加。
- 后台 ECharts 近 30 天浏览量折线图。这是前端图表，不是 Spring 模块。

前端里还有一块和 Spring 模块无关、但值得在别的笔记里记一笔，不占编号：

- Markdown：后台编辑用 md-editor-v3；前台渲染用 markdown-it + highlight.js，并用 DOMPurify 清洗。学的是「存储 Markdown、展示前消毒」，不是题目答案本身。
