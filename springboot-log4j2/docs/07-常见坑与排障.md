# 常见坑与排障

| 现象 | 原因 | 处理 |
|---|---|---|
| status 仍是 Logback | common/web 未排除 logging | 两端都 exclude |
| Async 报 Disruptor 相关错 | 未加 lmax disruptor | 加依赖 |
| `log4j2.xml` 里 `spring:` 不生效 | 加载过早 | 改用 `log4j2-spring.xml` |
| 日志文件找不到 | 相对路径看 cwd | 运行目录下 `logs/springboot-log4j2` |
| 与 #18 功能重复 | 边界不清 | 本模块只做替换 + 异步对比 |
