# 验证步骤

```bash
cmd /c "mvn -pl springboot-log4j2 -am spring-boot:run"
```

| 请求 | 期望 |
|---|---|
| `GET /api/log4j2/status` | `log4j2=true`，factory 含 log4j |
| `GET /api/log4j2/sample` | 响应头 `X-Trace-Id`，控制台有 traceId |
| `GET /api/log4j2/async-burst?lines=2000` | 返回 costMs |
| `GET /api/log4j2/sync-burst?lines=2000` | 通常慢于 async（视磁盘而定） |
