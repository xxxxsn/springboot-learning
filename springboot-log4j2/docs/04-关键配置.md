# 关键配置

## Maven

对 `springboot-common` / `spring-boot-starter-web` / test 排除 `spring-boot-starter-logging`，再引入 `spring-boot-starter-log4j2` + disruptor。

## log4j2-spring.xml

- Console + RollingFile（同步 Root）
- Async Appender + AsyncLogger（`com.xiesn.springboot.log4j2.demo`）
- Pattern 含 `%X{traceId}`
- 日志目录：`logs/springboot-log4j2/`
