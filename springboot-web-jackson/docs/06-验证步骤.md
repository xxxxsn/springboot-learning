# 验证步骤

```bash
mvn -pl springboot-web-jackson -am test
```

启动：

```bash
mvn -pl springboot-web-jackson -am spring-boot:run
```

然后打开 `api.http`。

| 请求 | 期望 |
|---|---|
| `GET /api/jackson/overview` | `enterprise.id` 为字符串；`plain.status` 为 `PAID`；`rawPlainJson` 含 `T08:30:00` 和 `"remark":null` |
| `GET /api/jackson/orders/sample` | `status=20`，没有 `remark` |
| `POST /api/jackson/orders` 字符串 id + 状态码 20 | 回显同样的字符串 id 和码 |
| `POST` 数字 id + `"PAID"` | 仍回显字符串 id 和 `20` |
| `POST` 的 `createdAt` 用 `2026-11-23T08:30:00` | `code=400` |
