# 关键配置

```yaml
server.port: 8026
spring.jackson.serialization.write-dates-as-timestamps: false
spring.jackson.date-format: yyyy-MM-dd HH:mm:ss
spring.jackson.time-zone: Asia/Shanghai
spring.jackson.default-property-inclusion: non_null
```

`date-format` 和 `time-zone` 只影响 `java.util.Date`。`LocalDateTime` 在 `JacksonDemoConfig` 里用 `Jackson2ObjectMapperBuilderCustomizer` 配成 `yyyy-MM-dd HH:mm:ss`。

不要把所有 `Long` 全局转成字符串。分页、金额若也是 `Long`，前端数字运算会坏。主键字段单独加 `ToStringSerializer`。
