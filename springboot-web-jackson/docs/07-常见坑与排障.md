# 常见坑与排障

| 现象 | 原因 | 处理 |
|---|---|---|
| 配了 `date-format`，`LocalDateTime` 仍是 ISO-8601 | 该配置只作用于 `java.util.Date` | 用 `Jackson2ObjectMapperBuilderCustomizer` 注册 `LocalDateTimeSerializer` |
| `LocalDateTime` 变成 `[2026,11,23,8,30]` | `JavaTimeModule` 默认把时间写成数组 | 关掉 `SerializationFeature.WRITE_DATES_AS_TIMESTAMPS`（Boot 已默认关掉） |
| 前端 ID 末位变成 0 或少 1 | JSON number 进 JS 后超出 `Number.MAX_SAFE_INTEGER` | 主键单独 `ToStringSerializer`，读入兼容数字和字符串 |
| 全局 `Long` 转字符串后金额也变成字符串 | `serializerByType(Long.class)` 一刀切 | 只注解主键字段 |
| 枚举名和数字码来回变 | 漏了 `@JsonValue` / `@JsonCreator` | 写在枚举上，并兼容历史客户端传的名字 |
| 某个 null 字段必须给前端 | 全局 `non_null` | 该字段加 `@JsonInclude(ALWAYS)` |
| `R.data` 为 null 时整个 data 消失 | `R` 类自身有 `@JsonInclude(NON_NULL)` | 这是 common 的信封约定，业务 null 看 DTO |
