# 核心代码要点

样例主键 `9007199254740993`（2^53+1）。按 JS Number 往返后变成 `9007199254740992`。

| 字段 | 企业订单 | 普通订单（仍走 Spring ObjectMapper） | 默认 ObjectMapper |
|---|---|---|---|
| id | 字符串 | JSON number | JSON number |
| createdAt | `yyyy-MM-dd HH:mm:ss` | 同左（全局） | `2026-11-23T08:30:00`（已关时间戳；不关则是数组） |
| paidAt | `yyyy/MM/dd HH:mm`（字段覆盖） | 无此字段 | 无此字段 |
| legacyTime | yml 的 Date 格式 | 无此字段 | 无此字段 |
| status | `20` | `PAID`（另一个没加 `@JsonValue` 的枚举） | `PAID` |
| remark=null | 省略 | 省略 | `"remark":null` |
| channel=null | 保留 null | 无此字段 | 无此字段 |

`@JsonValue` 写在枚举类型上，所有使用处都会变成数字码。要看默认枚举名，必须换一个没有该注解的枚举，不能只是「DTO 不加注解」。
