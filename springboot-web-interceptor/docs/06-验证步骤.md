# 验证步骤

```bash
cmd /c "mvn -pl springboot-web-interceptor -am test"
cmd /c "mvn -pl springboot-web-interceptor -am spring-boot:run"
```

| 请求 | 期望 |
|---|---|
| `GET /api/interceptor/chain` | `chain` 含 filter/interceptor/controller；有 `X-Cost-Ms` |
| `GET /secure/ping` 无 Token | HTTP 401 |
| `GET /secure/ping` + `X-Demo-Token` | HTTP 200 |
| `GET /session` | `activeSessions >= 1` |
