# 核心代码要点

## 典型顺序（本模块可观测）

1. `listener:request-init`
2. `filter:trace`（全局）
3. `filter:auth`（仅 `/secure/**`）
4. `interceptor:loginUser` → `interceptor:preHandle`
5. `controller:*`
6. `interceptor:postHandle` → `interceptor:afterCompletion`
7. `listener:request-destroy`（响应结束后，接口 body 里通常看不到）

## 企业取舍

| 诉求 | 放哪 |
|---|---|
| 与 Spring MVC 无关也要执行 | Filter |
| 需要 Handler / 注解元数据 | Interceptor |
| Session 创建销毁、请求进出 | Listener |
| 完整认证授权 | Spring Security（对照，不在本模块） |
