# 常见坑与排障

| 现象 | 原因 | 处理 |
|---|---|---|
| Interceptor 拦不住静态资源/部分错误 | 没进 DispatcherServlet | 早期逻辑放 Filter |
| Filter 顺序乱 | 只加了 `@Component` | 用 `FilterRegistrationBean#setOrder` |
| Filter 被注册两次 | 既是 `@Component` 又 `RegistrationBean` | 二选一 |
| `@WebListener` 不生效 | 未 `@ServletComponentScan` | 用 `@Component` 注册 Listener |
| Listener 计数翻倍 | 既是 Listener `@Bean` 又 `ServletListenerRegistrationBean` | 二选一，不要重复注册 |
| MockMvc 看不到 Listener | MockMvc 不走完整 Servlet 监听回调 | 用 `RANDOM_PORT` 容器测试 |
| afterCompletion 里读不到业务返回体 | 设计如此 | 要包装响应体用 Filter / Advice |
