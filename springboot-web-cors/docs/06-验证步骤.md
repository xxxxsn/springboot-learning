# 验证步骤

```bash
mvn -pl springboot-web-cors -am test
```

启动：

```bash
mvn -pl springboot-web-cors -am spring-boot:run
```

| 请求 | 期望 |
|---|---|
| `GET /api/cors/overview`，`Origin: https://admin.example.com` | 200，`Access-Control-Allow-Origin` 为该源，`Allow-Credentials: true` |
| 同一个地址不带 Origin | 200，没有 Allow-Origin |
| `Origin: https://evil.example.com` | 403 |
| `OPTIONS /api/cors/messages`，预检 POST + `Content-Type` | 200，Allow-Methods 含 POST，Max-Age 为 1800，没有 `code` |
| `GET /api/cors/shop`，商城源 | 200，Allow-Origin 为商城 |
| `GET /api/cors/shop`，管理端源 | 200，并集仍放行 |
| `GET /api/plain/ping` 带管理端 Origin | 200，`data=pong`，没有 Allow-Origin |
| `OPTIONS /api/plain/ping` 预检 | 403，正文 `Invalid CORS request` |

curl 能看到响应头。浏览器是否把响应交给页面，还要看这些头。MockMvc 只验证服务端写出的头。
