# 核心代码要点

浏览器流程：

1. 简单请求带 `Origin`。允许则响应里回显这个源，并带 `Access-Control-Allow-Credentials: true`
2. 非简单请求先发 `OPTIONS` 预检，带 `Access-Control-Request-Method`。预检成功时没有业务体
3. `Access-Control-Expose-Headers` 之外的响应头，前端脚本读不到。总览接口因此写出 `X-Demo-Token`

`@CrossOrigin` 不会替换全局配置。`/shop` 同时接受管理端和商城；`/overview` 只接受管理端。

`/api/plain/**` 没有映射。带 `Origin` 的 GET 仍返回业务 JSON，但没有 `Access-Control-Allow-Origin`。同样的预检被 Spring 的预检处理器收成 `403`，正文是 `Invalid CORS request`。
