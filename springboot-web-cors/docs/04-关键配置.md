# 关键配置

```yaml
server.port: 8029
```

全局映射 `/api/cors/**`：

| 项 | 值 |
|---|---|
| allowedOrigins | `https://admin.example.com` |
| allowedMethods | GET、POST、PUT、DELETE |
| allowedHeaders | `*` |
| exposedHeaders | `X-Demo-Token` |
| allowCredentials | true |
| maxAge | 1800 秒 |

`/api/cors/shop` 上的 `@CrossOrigin(origins = "https://shop.example.com")` 与上面的源站取并集。
