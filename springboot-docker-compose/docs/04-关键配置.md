# 关键配置

## application.yml

```yaml
spring:
  docker:
    compose:
      file: compose.yaml
      enabled: true
      lifecycle-management: start-and-stop
```

lifecycle 取值：`none` / `start-only` / `start-and-stop`。

从 IDE / 仓库根启动时，`ComposeFileEnvironmentPostProcessor`（优先级高于 application.yml）会把 `spring.docker.compose.file` 设为绝对路径。注意：`setDefaultProperties` 优先级低于 yml，不能靠它覆盖。

## compose.yaml 要点

- Redis：镜像名含 `redis` → 自动 `DataRedisConnectionDetails`
- `ports: ["6379"]`：宿主机临时端口，由 Boot 发现
- `labels: org.springframework.boot.ignore`：跳过建连
- 建议写 `healthcheck`，Boot 也会做 TCP readiness

## 测试

`src/test/resources/application.yml` 将 `skip.in-tests` 设为 `false`。
