# 核心代码要点

1. 引入 `spring-boot-docker-compose` 后，启动时搜索 compose 文件并 `up`
2. 按容器镜像名创建 Service Connection（Redis / MySQL / Mongo…）
3. 自动配置优先使用 Service Connection，而不是 `application.yml` 里的 host/port
4. 进程退出时按 lifecycle 执行 `stop`（默认不删 volume；`down` 才会）
5. fat jar 默认不包含该模块（`excludeDockerCompose`）；生产环境应关掉，改连真实中间件
