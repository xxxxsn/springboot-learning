# 验证步骤

前置：Docker Desktop / Engine 已启动。

```bash
mvn -pl springboot-docker-compose -am spring-boot:run
```

| 请求 | 期望 |
|---|---|
| `GET /api/docker-compose/status` | composeFile=compose.yaml |
| `GET /api/docker-compose/redis/ping` | output=PONG |
| `GET /api/docker-compose/redis/round-trip` | matched=true |

单测（需 Docker）：

```bash
mvn -pl springboot-docker-compose -am test
```
