# 常见坑与排障

| 现象 | 原因 | 处理 |
|---|---|---|
| `'files' content [compose.yaml] must exist` / 读到仓库根下的 compose.yaml | IDE/命令行 `user.dir` 在仓库根，yml 相对路径被解析错；`setDefaultProperties` 盖不过 yml | 启动时 `System.setProperty(spring.docker.compose.file, 绝对路径)`（main + EPP）；仍失败看控制台 `[docker-compose] main set compose file ->` |
| 连不上 Redis / 连到旧实例 | 手写了 `localhost:6379`，与临时映射端口不一致 | 删掉手写 host/port，用 Service Connection |
| 测试失败 No Redis | 默认 `skip.in-tests=true` | 本模块测试已改为 false；无 Docker 的 CI 请跳过本模块测试 |
| 容器已在跑 | Boot 只建连，不再 up，也不在退出时 stop | 预期行为；要统一生命周期先 `compose down` |
| fat jar 无 compose 支持 | 插件默认 exclude | 仅开发用；生产连 K8s/云中间件 |
| 镜像拉取慢 | 首次 pull | 提前 `docker pull redis:7.4` |
