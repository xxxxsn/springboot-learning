# 核心代码要点

一次请求的分工：

1. `DemoUserFilter` 读请求头，合法时 `request.setAttribute(LoginUser)`
2. `CurrentUserArgumentResolver` 只认 `@CurrentUser`。有用户就注入；`required=false` 注入 null
3. 方法若标了 `@ApiResult`，`ApiResultReturnValueHandler` 写出 `R.ok(返回值)`
4. 返回值本身已是 `R` 时原样写出
5. 没标 `@ApiResult` 的方法仍走 `@RestController` 的消息转换器

`addArgumentResolvers` 加在 ModelAttribute 兜底之前，所以自定义注解能抢到复杂类型参数。

`addReturnValueHandlers` 加在 `RequestResponseBodyMethodProcessor` 之后。`@RestController` 的方法都会被后者认领，自定义返回值处理器不会执行。本模块在适配器初始化后把处理器插到列表首位。
