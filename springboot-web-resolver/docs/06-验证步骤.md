# 验证步骤

```bash
mvn -pl springboot-web-resolver -am test
```

启动：

```bash
mvn -pl springboot-web-resolver -am spring-boot:run
```

| 请求 | 期望 |
|---|---|
| `GET /api/resolver/overview` | `code=0`，`data.port=8028` |
| `GET /me` 无请求头 | `code=401`，文案「缺少当前用户」 |
| `GET /me` 且 `X-User-Id: 7`、`X-User-Name: ada` | `data.id=7`，`data.name=ada` |
| `GET /me/optional` 无请求头 | `data.guest=true`，`data.name=guest` |
| `GET /already-wrapped` | `data` 是字符串 `kept`，不是再套一层 `R` |
| `GET /plain` 带用户头 | JSON 根上是 `name`，没有 `code` |

启动日志应有一行：`[resolver] ApiResult 返回值处理器已插入首位`。
