# 常见坑与排障

| 现象 | 原因 | 处理 |
|---|---|---|
| 方法参数上的注解不生效 | 类上缺 `@Validated` | Controller/Service 加 `@Validated` |
| PUT 总报 id 为空 | `@Validated` 在 `setId` 之前执行 | 先写路径 id，再 `validator.validate` |
| 只有第一条错误 | 落到了 common 默认处理器 | 确认本模块 Advice 优先级更高 |
| `@Mobile` 对空串也过 | 设计为 null/blank 放行 | 叠加 `@NotBlank` |
| 嵌套对象错误没出来 | 忘了 `@Valid`，或子约束在 Default 组而分组未继承 Default | 加 `@Valid`；分组接口 `extends Default` |
| 只校验 Create 时地址 `@NotBlank` 失效 | 未写 groups 的约束属 Default | `Create/Update extends Default` |
