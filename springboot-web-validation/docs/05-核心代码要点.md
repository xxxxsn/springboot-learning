# 核心代码要点

| 类 | 要点 |
|---|---|
| `@Mobile` / `MobileValidator` | null/blank 放行，必填叠加 `@NotBlank` |
| `@EnumValue` | 默认按 `Enum.name()`；可指定 `method` |
| `Create` / `Update` | 均 `extends Default`；Create：`id` 必须 null；Update：`id` 必填 |
| `UserSaveRequest` | 嵌套 `address` + `@Valid` |
| `ValidationExceptionAdvice` | `@Order(HIGHEST_PRECEDENCE)`，`R.data` 为字段错误列表 |
| `PUT /users/{id}` | 先 `setId` 再 `validator.validate(..., Update.class)` |

失败响应：

```json
{
  "code": 400,
  "message": "参数校验失败",
  "data": [{"field":"mobile","message":"手机号格式不正确"}]
}
```
