# 验证步骤

```bash
cmd /c "mvn -pl springboot-web-validation -am test"
cmd /c "mvn -pl springboot-web-validation -am spring-boot:run"
```

| 请求 | 期望 |
|---|---|
| `GET /api/validation/overview` | `code=0` |
| `POST /api/validation/users` 合法体 | 创建成功 |
| 非法手机号 + 非法枚举 | `code=400`，`data` 多字段 |
| 嵌套 `address.city=""` | `data[0].field=address.city` |
| `PUT /users/1001` | `data.id=1001` |
| `GET .../check-mobile?mobile=abc` | 方法级失败 |
| `POST /api/validation/manual` 非法体 | 手动校验失败 |
