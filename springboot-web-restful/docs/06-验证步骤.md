# 验证步骤

```bash
cmd /c "mvn -pl springboot-web-restful -am test"
cmd /c "mvn -pl springboot-web-restful -am spring-boot:run"
```

| 请求 | 期望 |
|---|---|
| `GET /api/restful/overview` | `code=0`，含 verbs 表 |
| `POST /api/articles` | `201`，`Location: /api/articles/{id}` |
| `GET /api/articles?keyword=REST` | 分页 `records` |
| `DELETE` 已存在 id | `204` 无 body |
| `GET /api/restful/styles/envelope/999999` | HTTP 200，`code=404` |
| `GET /api/restful/styles/status/999999` | HTTP 404，`code=404` |
