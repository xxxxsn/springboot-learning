# 核心代码要点

| 类 | 要点 |
|---|---|
| `ArticleController` | 动词语义；201 Location；204 删除；404 时 body 仍可包 `R` |
| `RestfulOverviewController` | 约定表；`styles/envelope` vs `styles/status` |
| `ArticleService` | 内存 Map；`requireById` 抛 `BusinessException(NOT_FOUND)` |
| `R` / `PageResult` | 统一信封与分页，来自 common |

**两种失败风格**

1. 信封：抛 `BusinessException` → common 处理器 → **HTTP 200** + `code=404`
2. 状态：Controller 返回 `ResponseEntity.status(404).body(R.fail(...))` → **HTTP 404** + `code=404`
