# 常见坑与排障

| 现象 | 原因 | 处理 |
|---|---|---|
| 业务失败仍是 HTTP 200 | common `GlobalExceptionHandler` 只回 `R`，未改状态码 | 需要 HTTP 语义时用 `ResponseEntity`；或等 #25 |
| DELETE 返回 200 + 空 R | 写成了 `R.ok()` | 成功删除用 `noContent()` |
| POST 没有 Location | 只 `return R.ok(created)` | `ResponseEntity.created(uri).body(...)` |
| PUT/PATCH 语义混用 | PUT 缺字段当部分更新 | PUT 全量；PATCH 允许 null 跳过 |
| 校验错误看不懂 | 只接了浅 `@NotBlank` | 分组/自定义注解见 #24 |
