# 验证步骤

```bash
cmd /c "mvn -pl springboot-profiles -am spring-boot:run"
```

| 请求 | 期望（dev） |
|---|---|
| `GET /api/profiles/overview` | active 含 dev，envName=dev，multidocFlag=multidoc-dev |
| `GET /api/profiles/banner` | DevEnvBanner |

production 组：

```bash
cmd /c "mvn -pl springboot-profiles spring-boot:run -Dspring-boot.run.arguments=--spring.profiles.active=production"
```

期望 active 含 production/proddb/prodmq，datasourceLabel=mysql-proddb，message=hello-from-prodmq。
