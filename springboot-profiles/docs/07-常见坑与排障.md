# 常见坑与排障

| 现象 | 原因 | 处理 |
|---|---|---|
| profile 专用文件里写 `spring.profiles.active` 不生效 | active 只能放在非 profile 文档 | 写到 `application.yml` 或命令行 |
| group 定义在 `application-xxx.yml` 无效 | group 只能定义在非 profile 专用文档 | 放回主 `application.yml` |
| 缺少 local-override 启动失败 | 没用 `optional:` | 使用 `optional:file:` |
| Compose profile 与 Spring profile 混淆 | 完全不同机制 | Compose 见 #17 / docker；本模块是 Boot Environment |
| PowerShell `-D` 被拆开 | PS 解析问题 | `cmd /c "mvn ... -Dspring-boot.run.arguments=..."` |
