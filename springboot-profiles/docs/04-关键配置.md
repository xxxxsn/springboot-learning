# 关键配置

## 激活

```yaml
spring:
  profiles:
    active: dev
    default: dev
    group:
      production:
        - proddb
        - prodmq
  config:
    import: optional:file:./config/local-override.yml
```

等价激活：`--spring.profiles.active=production`、环境变量 `SPRING_PROFILES_ACTIVE`。

## 本地覆盖

复制 `config/local-override.yml.example` → `config/local-override.yml`，可改 `demo.import-hint`。
