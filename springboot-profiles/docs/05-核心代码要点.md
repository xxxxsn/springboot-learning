# 核心代码要点

1. **分层文件**：`application.yml` 公共 + `application-{profile}.yml`
2. **Group**：激活 `production` 时展开 `proddb`、`prodmq`
3. **多文档**：`---` + `spring.config.activate.on-profile`，同文件内按 profile 合并
4. **import**：`optional:file:` 缺失不失败；存在时覆盖导入方同名键
5. **`@Profile`**：无匹配时 `List<EnvBanner>` 为空
6. **优先级（简化）**：命令行 > 系统属性/环境变量 > import 文件 > profile yml > 默认 yml
