# 核心代码要点

| 类 | 作用 |
|---|---|
| `HelloApplication` | 启动类；排除对 `HelloAutoConfiguration` 的组件扫描，强制走 imports |
| `HelloProperties` | `@ConfigurationProperties(prefix=demo.hello)` |
| `HelloService` | 问候语拼装 |
| `HelloAutoConfiguration` | `@AutoConfiguration` + 条件装配 Bean |
| `HelloController` | `/api/hello`、`/config`、`/boom` |
| `HelloStartupRunner` | `ApplicationRunner` 启动完成后打日志 |

imports 文件：

`src/main/resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`
